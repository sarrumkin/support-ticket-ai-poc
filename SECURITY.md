# Security Policy

Проект является локальным учебным PoC и не предназначен для обработки реальных пользовательских
данных или production traffic.

Уязвимости и случаи возможной утечки данных не следует публиковать в обычных issues. Используйте
[private vulnerability report](https://github.com/sarrumkin/support-ticket-ai-poc/security/advisories/new).
Поддерживаемая версия — текущая ветка `main`; исправления выпускаются в режиме best effort.
